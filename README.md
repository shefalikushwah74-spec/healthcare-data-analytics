\# Healthcare Data Analytics \& SQL Pipeline



\## Overview



This project analyzes a healthcare dataset containing 55,500 patient records.



The project combines Python, Pandas, MySQL, SQLAlchemy and data visualization to explore patient demographics, medical conditions, hospital activity, admission patterns and billing information.



\## Tools Used



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- MySQL

\- SQLAlchemy

\- PyMySQL

\- Jupyter Notebook



\## Project Workflow



1\. Loaded and explored healthcare data using Pandas.

2\. Performed data validation and quality checks.

3\. Created a MySQL database and healthcare table.

4\. Loaded 55,500 records into MySQL.

5\. Used SQL aggregation and grouping for analysis.

6\. Connected MySQL with Python using SQLAlchemy.

7\. Created visualizations using Matplotlib.

8\. Generated analytical summaries for reporting.



\## Analysis Performed



\- Patient distribution by medical condition

\- Patient demographics

\- Admission type analysis

\- Insurance provider analysis

\- Average billing by medical condition

\- Hospital patient volumes

\- Age distribution

\- Data-quality validation



\## Key Findings



\- The dataset contains 55,500 patient records.

\- Average patient age is approximately 51.54 years.

\- Six major medical conditions are represented.

\- 108 records contain negative billing amounts and were identified during data-quality validation.

\- SQL aggregation was used to compare patient volume and billing across medical conditions.
